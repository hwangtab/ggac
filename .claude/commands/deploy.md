배포 전 안전 점검 후 배포를 진행해줘:

1. `git status`로 미커밋 변경사항 확인
   - 미커밋 변경이 있으면 배포 전에 커밋할지 물어봐줘
2. `git log --oneline -5`로 최근 커밋 확인
3. 배포 환경 선택을 물어봐줘:
   - **프리뷰** (기본): `npm run vercel:preview`
   - **프로덕션**: `npm run vercel:deploy` (한번 더 확인 필요)
4. 선택한 환경으로 배포 실행
5. 배포 완료 후 배포된 URL 출력

⚠️ 프로덕션 배포는 반드시 사용자 확인 후 진행해줘.
