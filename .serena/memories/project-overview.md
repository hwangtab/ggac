# 경기아트콜렉티브 웹사이트 프로젝트 개요

## 프로젝트 목적
경기아트콜렉티브 협동조합(Gyeonggi Art Collective Cooperative)의 공식 웹사이트로, 아티스트와 프로젝트를 소개하는 공개 사이트와 멤버 전용 게시판 시스템을 결합한 플랫폼입니다.

## 주요 기능
- **공개 콘텐츠**: 아티스트 프로필, 프로젝트 아카이브, 협동조합 소개
- **멤버 게시판**: 승인된 멤버만 접근 가능한 커뮤니티 공간
- **관리자 시스템**: 멤버 승인, 콘텐츠 관리, 통계 모니터링
- **마이페이지**: 개인 프로필 관리 및 아티스트 정보 편집

## 기술 스택
- **프레임워크**: Next.js 14 (App Router)
- **언어**: TypeScript (strict mode)
- **스타일링**: Tailwind CSS
- **인증/DB**: Supabase (PostgreSQL + Auth)
- **배포**: Vercel
- **테스팅**: Playwright + 커스텀 테스트 스크립트

## 데이터 아키텍처
- **공개 콘텐츠**: JSON 파일 기반 (`/data` 디렉토리)
- **멤버 시스템**: Supabase 데이터베이스 (RLS 정책 적용)
- **이미지**: Next.js 최적화 + WebP 지원
