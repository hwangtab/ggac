# 경기아트콜렉티브 협동조합 웹사이트 프로젝트

## 프로젝트 목적

경기아트콜렉티브 협동조합의 공식 웹사이트로, 예술가들의 창의적 활동과 협동조합의
철학을 디지털 공간에서 표현하며, 방문자들이 몰입감 있는 예술적 경험을 할 수
있도록 설계된 플랫폼입니다.

## 기술 스택

- **Framework**: Next.js 15.4.4 (App Router 사용)
- **Language**: TypeScript (strict: false)
- **Styling**: Tailwind CSS
- **Database**: Supabase
- **State Management**: Zustand
- **Authentication**: Supabase Auth
- **Markdown**: react-markdown
- **Rich Text Editor**: React Quill
- **Image Processing**: Sharp
- **Animation**: 커스텀 파티클 시스템 (WebGL, CSS, Canvas)
- **Testing**: Playwright
- **Deployment**: Vercel

## 주요 기능

- 정적 콘텐츠 관리 (JSON 기반)
- 회원 관리 및 인증 시스템
- 게시판 및 댓글 시스템
- 이미지 최적화 및 업로드
- 실시간 알림
- 관리자 대시보드
- 다양한 인터랙티브 파티클 효과
