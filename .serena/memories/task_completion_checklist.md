# 작업 완료 시 체크리스트

## 코드 작성 후 필수 단계

### 1. 코드 품질 검사

```bash
npm run lint
```

- ESLint 오류 수정 필수

### 2. 빌드 테스트

```bash
npm run build
```

- 빌드 오류 해결 필수
- TypeScript 타입 오류 수정

### 3. E2E 테스트 (주요 기능 변경 시)

```bash
npx playwright test
```

### 4. 번들 크기 확인 (성능 최적화 시)

```bash
ANALYZE=true npm run build
```
