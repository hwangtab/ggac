# 조합원 '내 문서함' — 마이페이지에서 문서를 올리고 앱 안에서 고치기

> 2026-11-04 작성. 이사회 업무툴(`01-설계.md` §7·§8, `03-통합-재설계.md`)이 이미
> 가진 비공개 Blob 직접 업로드·미리보기·오피스/HWP 편집기를 **조합원 개인
> 문서함** 으로 넓힌다. 결정은 사용자 승인을 받았다(§10).

## 0. 한 줄 요약

승인·활성 조합원은 마이페이지 → **내 문서함**(`/mypage/documents`)에서 자기
문서만 올리고, 미리 보고, 내려받고, 이름을 바꾸고, 지우고, 버전을 되돌리고,
PC에서는 ggac-office 편집기(Word·Excel·PPT·HWP·HWPX)로 고친다. 한 사람 200MB,
1년 동안 열지 않은 문서는 알리고 30일 뒤 지운다. 기능 스위치는 **기본
꺼짐**이다.

## 1. 범위

### 하는 것

- 목록(이름·형식·크기·고친 때) + 사용량 막대(200MB)
- 올리기(브라우저 → 비공개 Blob 직접 업로드), 새 문서(DOCX·XLSX·PPTX·HWPX 빈
  서식)
- 미리보기(이미지·PDF·텍스트·kordoc 문서/시트·HWP 쪽 모양), 내려받기
- 이름 바꾸기, 지우기, 버전 기록(되돌리기 = 그 버전을 복사해 새 최신 버전)
- 편집 화면(PC 전용 — 모바일은 미리보기·내려받기만). HWP·HWPX에는 rhwp 초기 단계
  경고 띠
- 보존 크론(1년 미사용 → 알림, 그 뒤 30일 → 삭제)과 임시 업로드 정리

### 하지 않는 것

- 공유·공동 편집·폴더·검색·본문 추출(업무툴의 `work_attachment_texts`류)· 수정
  중 표시(checkout — 혼자 쓰는 문서함이라 필요 없다)
- 관리자 열람 화면. 사무국도 남의 문서함을 보지 못한다(§4)
- 새 HWP(.hwp) 빈 문서 — 업무툴도 서식이 HWPX뿐이다(`public/doc-templates`).
  올린 .hwp 파일의 편집은 된다
- 탈퇴 회원 문서의 즉시 삭제(보존 규칙이 1년 뒤 정리한다 — §6-3)
- HWP 양식 채우기·문구 고치기(`doc-edit`) — 업무툴 전용으로 남긴다

## 2. 데이터 모델 (마이그레이션 `0036_member_documents.sql`)

업무툴 관례를 따른다: 사람 FK는 `member_profiles`, CHECK 없음(허용값은 zod·쿼리
계층이 지킨다), 시각은 epoch ms.

```
member_documents                문서 한 건(최신 버전 번호·보존 상태)
  id                 text pk (uuid)
  owner_id           text → member_profiles.id  ON DELETE CASCADE
  name               text  표시 이름(확장자 포함). 이름 바꾸기가 고치는 곳
  latest_version_no  integer
  last_opened_at     integer(ms)  열거나 고친 때 — 보존 판정의 기준
  deletion_notified_at integer(ms) NULL  1년 미사용 알림을 보낸 때
  created_at / updated_at

member_document_versions        버전 한 벌 = Blob 객체 하나
  id                 text pk (uuid) = 객체 키의 업로드 id 구간
  document_id        → member_documents.id ON DELETE CASCADE
  owner_id           → member_profiles.id  (사용량 합계·소유 재확인)
  version_no         integer  UNIQUE(document_id, version_no)
  name, mime, size, blob_path(UNIQUE)
  source             'upload' | 'editor' | 'restore'
  created_at

member_document_uploads         임시 업로드(토큰 발급 근거)
  id                 text pk (uuid) — 승격하면 버전 id가 된다
  owner_id           → member_profiles.id
  document_id        → member_documents.id NULL(새 문서) / 대상 문서(새 버전)
  blob_path(UNIQUE), name, mime, size, created_at
```

- 최신 버전은 `latest_version_no`로 고른다(업무툴의 `is_latest` 대신 — 계보가 한
  문서 안에서 끝나므로 열 하나면 된다).
- 버전 행은 지우지 않는다(되돌리기 대상). 문서를 지우면 버전·임시 업로드가
  CASCADE로 지워지고, 객체는 라우트가 먼저 지운다(§3-3).

## 3. 저장소

### 3-1. 경로

```
member-documents/<ownerId uuid>/<uploadId uuid>/<ASCII 안전 이름>    원본(버전마다)
board-work/renders/<versionId>-<변환기 버전>…                       미리보기 캐시(업무툴과 공용)
```

- 같은 비공개 저장소에 DB 백업(`backups/`)·메일 첨부(`mailbox/`)·이사회 서류
  (`board-documents/`)·업무툴(`board-work/`)이 있다. **import 없는 순수 판정
  `isSafeMemberDocumentPath`**(`src/lib/storage/memberDocuments.ts`)가 위 한
  모양만 통과시키고, 문서함 저장소 계층의 모든 읽기·쓰기·삭제·복사가 첫 줄에서
  그것을 다시 본다. 소유자 구간이 요청한 사람과 같은지도 같이 본다
  (`isMemberDocumentPathOf(path, ownerId)`).
- 미리보기 캐시는 자료실의 이사회 서류(03 §10)처럼 업무툴 렌더 캐시를 그대로
  쓴다 (`renderFileResponse` — 캐시 키는 버전 id). 문서를 지우면 그 버전 id들의
  캐시를 `removeRenderCachesWith`로 지운다.

### 3-2. 토큰

`boardWorkBlobToken()`을 그대로 쓴다 — `BOARD_WORK_BLOB_READ_WRITE_TOKEN`이
정의돼 있으면(빈 값 포함) 그것만, 아니면 `PRIVATE_BLOB_READ_WRITE_TOKEN`. E2E는
이 변수를 늘 정의하므로(시험 저장소 토큰 또는 빈 값) 운영 저장소에 닿지 않는다.

### 3-3. 재사용 — 저장소 계층을 공장 함수로 뽑는다

업무툴 `src/work/lib/files/storage.ts`의 읽기·메타·쓰기·삭제·복사를
`createGuardedPrivateStore(guard)`(`src/work/lib/files/private-store.ts`)로
옮기고, 업무툴은 `isSafeBoardWorkPath`로, 문서함은 `isSafeMemberDocumentPath`로
한 벌씩 만든다. 오류 클래스(`StorageUnconfiguredError` 등)는 공용이라 미리보기
응답(`render-response.ts`)의 503 판정이 두 쪽에서 같다. 업무툴의 함수
이름·동작은 바뀌지 않는다.

## 4. 경로와 게이트

모든 API 핸들러의 첫 줄은 `requireActiveMember()`다(비로그인 401·미승인/정지
403). 그다음 기능 스위치(꺼지면 503), 그다음 **소유 판정** — 문서·버전·임시
업로드는 `owner_id = 나`인 행만 읽는다. 남의 id는 없는 id와 같은 404다(존재를
알리지 않는다). 관리자도 예외가 없다.

| 경로(`/api/mypage/documents…`) | 메서드 | 하는 일                                                               |
| ------------------------------ | ------ | --------------------------------------------------------------------- |
| ``                             | GET    | 내 목록 + 사용량                                                      |
| ``                             | POST   | 임시 업로드 → 새 문서 v1 (`{ uploadId, source }`)                     |
| `/status`                      | GET    | 메뉴 노출용 `{ enabled }`(스위치 꺼져도 200)                          |
| `/uploads`                     | POST   | ① `prepare`(사용량·형식·크기 판정 후 임시 행) ② SDK 토큰 요청         |
| `/uploads/[uploadId]`          | DELETE | 실패·취소한 임시 업로드 버리기                                        |
| `/[id]`                        | GET    | 문서 + 버전 목록(열람으로 센다)                                       |
| `/[id]`                        | PATCH  | 이름 바꾸기                                                           |
| `/[id]`                        | DELETE | 지우기(객체·캐시·행)                                                  |
| `/[id]/versions`               | POST   | 새 버전(`uploadId` — 올리기·편집기 저장) 또는 되돌리기(`restoreFrom`) |
| `/files/[versionId]`           | GET    | 원본 스트림(`?download=1`은 attachment, 이미지 inline). 열람으로 센다 |
| `/files/[versionId]/[name]`    | GET    | PDF·텍스트·이미지 inline(같은 출처 프레임만)                          |
| `/files/[versionId]/render`    | GET    | kordoc 미리보기(업무툴 `renderFileResponse`)                          |

- 페이지(`/[locale]/mypage/documents`, `/[id]`, `/[id]/edit`, `/new`)는 서버
  컴포넌트가 같은 판정을 한다: 비로그인 → 로그인, 미승인 → 안내, 스위치 꺼짐 →
  "준비 중", 남의 id → 404.
- 쓰기(업로드 준비·토큰·새 문서·새 버전·되돌리기·이름·삭제)는 분산 리미터
  `MEMBER_DOCUMENT_WRITE`(사용자 단위 분당 30), 편집기 저장본 검사는 업무툴과
  같은 `WORK_DOC_EDIT_DRAFT`(분당 10)를 문서함 이름으로 따로 센다
  (`MEMBER_DOCUMENT_VERIFY`). 미리보기는 업무툴 `WORK_RENDER`를 그대로 탄다.
- `scripts/testing/assert-runtime-risks.mjs`가
  `src/app/api/mypage/documents/**`의 모든 핸들러 본문에
  `requireActiveMember()`가 있는지, `[id]`·`[versionId]`· `[uploadId]` 경로에
  소유 판정 호출이 있는지, 보존 크론이 타이밍 안전 비교를 쓰는지 본다(보조다 —
  안전망은 `e2e/authz-member-documents.spec.ts`).

## 5. 사용량 (200MB)

- 사용량 = **내 모든 버전의 크기 합** + **24시간 안의 임시 업로드가 알린 크기
  합** (올리는 중인 것도 자리를 잡는다 — 동시에 여러 개를 올려 한도를 넘지
  못하게).
- 판정은 두 번: ① 토큰 발급(`prepare`·토큰 요청) 때 `사용량 + 알린 크기 ≤ 200MB`
  ② 승격(새 문서·새 버전·되돌리기) 때 실제 크기(`head()`)로 다시. ②에서 넘으면
  객체를 지우고 413.
- 파일당 상한 50MB(편집기 상한과 같다), HWP·HWPX 편집 저장은 20MB(업무툴과
  같다).
- 순수 계산은 `src/lib/memberDocuments/rules.ts`(`quotaVerdict`).

## 6. 보존

### 6-1. 규칙

- `last_opened_at`이 365일보다 오래됐고 아직 알리지 않았으면 → **알림**
  (`deletion_notified_at = 지금`, 알림 + 메일).
- 알린 지 30일이 지났고 그 사이 열지
  않았으면(`last_opened_at ≤ deletion_notified_at`) → **삭제**(객체·캐시·행).
- 열기(상세 화면·내려받기·편집기 열기)와 새 버전은 `last_opened_at = 지금`,
  `deletion_notified_at = NULL`로 되돌린다.
- 순수 판정 `retentionActionOf(doc, now)`와 같은 조건을 SQL이 쓴다
  (`src/db/queries/memberDocuments.ts`).

### 6-2. 크론

`/api/internal/member-documents/retention` — 매일(`vercel.json`), `CRON_SECRET`
Bearer 타이밍 안전 비교(`isCronAuthorized` 재사용), 없으면 닫힌다(401). 한 번에
알림 200건·삭제 100건·임시 업로드 정리 200건. 알림은 사람마다 한 통으로 묶는다:

- 알림(`notifications`, 새 타입 `member_document_expiring` — DB CHECK가 없어 표
  변경 없음) → `/mypage/documents`로 이동
- 메일(Resend, `RESEND_API_KEY`가 있을 때만 — 펀딩 알림의 `renderNoticeEmail`
  재사용). 삭제 통지는 알림만 남긴다(메일은 경고 한 번).

### 6-3. 탈퇴·정지

정지·탈퇴 신청 회원은 문서함을 쓰지 못한다(게이트). 문서는 남아 있다가 보존
규칙이 지운다. `member_profiles` 행이 지워지면 표는 CASCADE로 비고, 객체는
남는다(지금 회원 행을 지우는 경로는 없다 — 생기면 그때 객체 정리를 붙인다).

## 7. 기능 스위치 `features/member_documents`

- 값 `{ enabled: boolean }`. **`=== true`일 때만 켜짐**(펀딩·타임뱅크처럼
  fail-closed — 행이 없거나 깨지면 꺼짐). 기본값 `enabled: false`
  (`getDefaultSettings`, 설정 초기화 행).
- 관리자 설정 화면 '기능 설정' 탭에 스위치 `member_documents_enabled`.
- 꺼지면: 마이페이지 메뉴에서 숨김, 페이지는 "준비 중" 안내, API는 503(게이트
  뒤라 비회원은 여전히 401/403). **읽기도 막는다** — 다른 스위치(게시판 등)와
  다른 점이다. 문서함은 출시 전 기능이라 켜기 전에는 아무것도 보이지 않아야
  한다.
- 권한 E2E 시드(`seed-authz-fixtures.mjs`)는 켠다.

## 8. 화면

- 마이페이지 레이아웃(`MypageLayout`·`MypageNavigation`) 안에서 그린다. 색은
  마이페이지 관례(`bg-white`·`border-gray-200`·`tw-btn-primary` — 포스터 테마가
  다크로 재매핑)를 쓴다.
- 미리보기 칸과 편집기 머리줄만 업무툴 부품(`FilePreviewBody`·`DocumentViewer`·
  `OfficeEditorFrame`·`HwpEditorFrame`)을 `data-work-app` 칸 안에 그대로 쓴다
  (`FileApiBaseContext`로 API 기준 경로만 문서함으로 바꾼다).
- 편집 화면은 PC 전용(`DesktopOnlyGate`와 같은 판정 `useDesktopEditorKnown`).
  모바일에서는 "PC에서 열어 주세요"와 미리보기·내려받기 링크.
- HWP·HWPX 편집 화면 위에 경고 띠: rhwp는 초기 단계라 제출 전 한컴오피스
  한글에서 저장한 파일을 열어 확인하라는 문구.
- 로그아웃: 문서함 편집기를 연 브라우저는 표식(`localStorage`)을 남기고,
  로그아웃 때 업무툴과 같은 `purgeOfficeEditorStorage()`로 편집기 출처 저장소를
  비운다.

## 10. 결정 (2026-11-04, 사용자 승인)

1. 대상: 승인·활성 조합원(`requireActiveMember`). 본인 문서만 본다.
2. 위치: 마이페이지 → 내 문서함(`/mypage/documents`).
3. 사용량 200MB(모든 버전 포함). 1년 미사용 → 알림, 30일 뒤 삭제(열면 초기화).
4. 기능 스위치 기본 꺼짐. 꺼지면 메뉴 숨김·페이지 "준비 중"·API 503. E2E는 켠다.
5. HWP 편집에는 경고 띠.
