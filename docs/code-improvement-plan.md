# 경기아트콜렉티브 웹사이트 코드 개선 계획

## 📋 개요

이 문서는 전체 코드 리뷰를 바탕으로 작성된 체계적인 개선 계획입니다.

## 🎯 개선 목표

- TypeScript 타입 안전성 강화
- 프로덕션 환경 최적화
- 코드 품질 및 유지보수성 향상
- 성능 최적화
- 테스트 커버리지 확대

## 🔴 Phase 1: 즉시 개선 필요 (높은 우선순위)

### 1.1 TypeScript 타입 안전성 강화

**목표**: `any` 타입 사용 최소화 및 타입 정의 완성

**문제점**:

```typescript
// 현재 문제 사례들
profile as any
;(comment as any).id(notification as any).read_at
```

**해결 방안**:

- [ ] 모든 Supabase 테이블에 대한 정확한 타입 정의
- [ ] API 응답 타입 인터페이스 정의
- [ ] `any` 타입을 구체적인 타입으로 교체
- [ ] tsconfig.json에서 `strict: true` 설정 검토

**예상 작업 시간**: 2-3일

### 1.2 프로덕션 환경 정리

**목표**: 개발용 디버그 로그 제거 및 에러 트래킹 시스템 구현

**문제점**:

- 프로덕션 환경에 다수의 `console.log` 잔존
- 특히 middleware, login, admin 영역에 집중

**해결 방안**:

- [ ] 모든 개발용 디버그 로그 제거
- [ ] 프로덕션 에러 트래킹 시스템 구현 (Sentry 등)
- [ ] 로깅 유틸리티 함수 작성
- [ ] 환경별 로그 레벨 설정

**예상 작업 시간**: 1-2일
