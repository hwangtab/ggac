# 아티스트 데이터 정합성 복원 실행 가이드

## 🚨 긴급 수정 필요 사항
황경하님(artist-008)의 데이터가 JSON 원본과 완전히 다른 내용으로 저장되어 있어 마이페이지 아티스트 프로필에 잘못된 정보가 표시되고 있습니다.

## 📋 실행 순서

### 1단계: 황경하님 데이터 복원 (필수)
```sql
-- Supabase SQL Editor에서 실행
-- 파일: scripts/fix-artist-008-data.sql
```
- **목적**: 잘못된 개발자 프로필을 실제 황경하님 정보로 교체
- **변경사항**: 이름, 한줄소개, 상세소개, 포트폴리오, 유튜브 등 전체
- **안전장치**: 백업 테이블 자동 생성

### 2단계: 아티스트 권한 설정 (필수)
```sql
-- Supabase SQL Editor에서 실행
-- 파일: scripts/fix-artist-permissions.sql
```
- **목적**: `is_artist` = true 설정으로 마이페이지 접근 권한 부여
- **변경사항**: `member_profiles` 테이블의 권한 관련 필드 업데이트
- **확인**: 권한 체크 시뮬레이션 포함

### 3단계: 전체 데이터 검증 (권장)
```sql
-- Supabase SQL Editor에서 실행
-- 파일: scripts/verify-all-artist-data.sql
```
- **목적**: 다른 아티스트들도 동일한 문제가 있는지 확인
- **기능**: JSON vs DB 데이터 비교, 무결성 검사
- **결과**: 문제가 있는 아티스트 식별

## 🔧 실행 방법

### Supabase Dashboard 접속
1. [Supabase Dashboard](https://supabase.com/dashboard) 로그인
2. 프로젝트 선택
3. 좌측 메뉴에서 **SQL Editor** 클릭

### 스크립트 실행
1. 각 SQL 파일의 내용을 복사
2. SQL Editor에 붙여넣기
3. **Run** 버튼 클릭
4. 결과 확인

## ✅ 예상 결과

### 1단계 완료 후
- 황경하님의 실제 프로필 정보가 데이터베이스에 저장됨
- 음악가/활동가로서의 올바른 소개글과 포트폴리오 링크
- 실제 음악 작품 유튜브 링크들

### 2단계 완료 후
- 마이페이지 `/mypage/artist` 페이지 정상 접근 가능
- "아티스트 권한이 필요합니다" 오류 해결
- 아티스트 프로필 편집 기능 사용 가능

### 3단계 완료 후
- 전체 아티스트 데이터 상태 파악
- 추가 수정이 필요한 아티스트 식별
- 데이터 완성도 리포트

## 🚀 테스트 방법

### 권한 테스트
1. 황경하님 계정으로 로그인
2. `/mypage/artist` 페이지 접속
3. 정상적으로 아티스트 프로필이 표시되는지 확인

### 데이터 테스트
1. 표시되는 이름, 소개글이 올바른지 확인
2. 포트폴리오 링크들이 정상 작동하는지 확인
3. 유튜브 영상들이 올바르게 임베드되는지 확인

### API 테스트
1. 개발자 도구에서 Network 탭 확인
2. `/api/mypage/artist` GET 요청이 200 응답하는지 확인
3. 프로필 수정 후 PATCH 요청이 정상 작동하는지 확인

## 🆘 문제 해결

### 스크립트 실행 실패 시
1. Supabase 프로젝트 권한 확인
2. SQL 문법 오류 점검
3. 테이블 존재 여부 확인

### 권한 설정이 안 될 시
1. `member_profiles` 테이블에 황경하님 레코드 존재 확인
2. 이메일 주소로 검색해서 올바른 레코드 식별
3. 수동으로 필드 값 업데이트

### 데이터가 여전히 틀릴 시
1. 브라우저 캐시 클리어
2. Next.js 캐시 무효화 (`npm run build`)
3. Supabase RLS 정책 재확인
