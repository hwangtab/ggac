- 2026-08-27 — 제7차 이사회 안건 2(예비 사회적기업 지정 신청 준비) 보고를 위해 최초 작성. 경기도 공고 제2026-339호 원문 기준

## 갱신 규칙

요건·서식·일정은 회차마다 바뀐다. **신청할 때마다 해당 회차 공고문 원문을 다시 확인하고 이 문서를 갱신한다.** 갱신 시 위 이력에 날짜와 근거 공고번호를 남긴다.
