# Scripts Directory

이 디렉터리는 프로젝트 관련 모든 스크립트와 유틸리티를 목적별로 정리한 공간입니다.

## 📁 디렉터리 구조

### `testing/`
테스트 관련 스크립트들
- `e2e/` - End-to-End 테스트 스크립트들
- `api/` - API 엔드포인트 테스트 스크립트들
- `security/` - 보안 관련 테스트들
- `performance/` - 성능 테스트 스크립트들

### `utils/`
유틸리티 및 도구 스크립트들
- `image-processing/` - 이미지 변환 및 최적화
- `data-migration/` - 데이터 이관 관련
- `deployment/` - 배포 관련 스크립트들

### `one-off/`
일회성 작업 스크립트들 (특정 이슈 해결용)

### `archive/`
사용 완료되었지만 참고용으로 보관하는 스크립트들

- `archive/supabase-board/` — 이사회 데이터를 **Supabase**에 쓰던 유지보수
  스크립트 8종(회의 제목 정리·장소 정리·회의 생성·회의록 복원·시드 2종·검증·
  안건/회의록 교정)이 있었다. 2026-09-07 Supabase 프로젝트 삭제와
  `@supabase/supabase-js` 의존성 제거에 맞춰 이 디렉터리 전체를 지웠다 — 이사회
  데이터의 권위는 이미 Turso(`src/db/queries/board.ts`)로 옮겨졌고, 되돌릴
  원본 자체가 더 이상 없다.

## 🚀 사용법

각 하위 디렉터리의 README.md 파일을 참조하여 해당 스크립트의 사용법을 확인하세요.
