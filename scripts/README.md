# Scripts Directory

이 디렉터리는 프로젝트 관련 모든 스크립트와 유틸리티를 목적별로 정리한 공간입니다.

## 📁 디렉터리 구조

### `database/`
데이터베이스 관련 스크립트들
- `migrations/` - SQL 마이그레이션 파일들
- `fixes/` - 긴급 수정/패치 스크립트들  
- `setup/` - 초기 설정 및 테이블 생성 스크립트들
- `checks/` - 데이터베이스 상태 확인 스크립트들

### `testing/`
테스트 관련 스크립트들
- `e2e/` - End-to-End 테스트 스크립트들
- `api/` - API 엔드포인트 테스트 스크립트들
- `security/` - 보안 관련 테스트들
- `performance/` - 성능 테스트 스크립트들

### `utils/`
유틸리티 및 도구 스크립트들
- `image-processing/` - 이미지 변환 및 최적화
- `data-migration/` - 데이터 이관 관련
- `deployment/` - 배포 관련 스크립트들

### `one-off/`
일회성 작업 스크립트들 (특정 이슈 해결용)

### `archive/`
사용 완료되었지만 참고용으로 보관하는 스크립트들

## 🚀 사용법

각 하위 디렉터리의 README.md 파일을 참조하여 해당 스크립트의 사용법을 확인하세요.

## ⚠️ 주의사항

- 프로덕션 환경에서 스크립트를 실행하기 전에 반드시 테스트 환경에서 먼저 검증하세요
- 데이터베이스 관련 스크립트는 백업 후 실행하세요
- 스크립트 실행 전에 해당 README를 반드시 읽어보세요
