# Scripts Directory

이 디렉터리는 프로젝트 관련 모든 스크립트와 유틸리티를 목적별로 정리한 공간입니다.

## 📁 디렉터리 구조

### `database/`
데이터베이스 관련 스크립트들
- `migrations/` - SQL 마이그레이션 파일들
- `fixes/` - 긴급 수정/패치 스크립트들  
- `setup/` - 초기 설정 및 테이블 생성 스크립트들
- `checks/` - 데이터베이스 상태 확인 스크립트들

### `testing/`
테스트 관련 스크립트들
- `e2e/` - End-to-End 테스트 스크립트들
- `api/` - API 엔드포인트 테스트 스크립트들
- `security/` - 보안 관련 테스트들
- `performance/` - 성능 테스트 스크립트들

### `utils/`
유틸리티 및 도구 스크립트들
- `image-processing/` - 이미지 변환 및 최적화
- `data-migration/` - 데이터 이관 관련
- `deployment/` - 배포 관련 스크립트들

### `one-off/`
일회성 작업 스크립트들 (특정 이슈 해결용)

### `archive/`
사용 완료되었지만 참고용으로 보관하는 스크립트들

- `archive/supabase-board/` — 이사회 데이터를 **Supabase**에 쓰던 유지보수
  스크립트 8종(회의 제목 정리·장소 정리·회의 생성·회의록 복원·시드 2종·검증·
  안건/회의록 교정). 단계 4에서 이사회 데이터의 권위가 Turso로 옮겨졌으므로
  이 스크립트들은 **버려진 사본에 쓰고 성공 메시지를 낸다** — 국장이 회의
  제목을 고쳐도 화면은 안 바뀌고 아무도 이유를 모른다(최종 리뷰 B-6).
  조용한 성공이 제일 나쁘므로 각 파일 맨 위에 **실행 즉시 중단(exit 1)** 가드가
  들어 있다. 다시 필요하면 `src/db/queries/board.ts`(Turso 쿼리 계층)를 쓰도록
  포팅해 `scripts/`로 되돌리고, 그때 가드를 지운다.

## 🚀 사용법

각 하위 디렉터리의 README.md 파일을 참조하여 해당 스크립트의 사용법을 확인하세요.

- 데이터베이스 관련 스크립트는 백업 후 실행하세요
- 스크립트 실행 전에 해당 README를 반드시 읽어보세요
